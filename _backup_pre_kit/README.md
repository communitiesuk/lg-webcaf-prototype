# lg-webcaf-prototype
Local Government WebCAF prototype: digitising CAF workbook journeys into a structured, auditable web flow (assessment, progress tracking, evidence linking).

## Purpose
This repository contains a prototype exploring how the Local Government CAF workbook process could be represented as a web service: structured outcomes, progress tracking, evidence linking, and review/approval checkpoints. (Prototype; not production-ready.)

## Status
- Phase: Prototype / Alpha exploration
- Data: TBC
- Hosting: TBC

## What’s in scope (prototype)
- Assessment setup (e.g. create an assessment / choose scope)
- Outcome navigation (Objectives → Principles → Contributing outcomes)
- Recording IGP responses + rationale
- Evidence referencing/linking
- Basic progress tracking (owner, status, due date)
- Review/approval stamps (where applicable)

> Note: This prototype is designed to model the workbook mental model without recreating spreadsheet UX.
